# M5 v2 Engine

M5 v2 is an enterprise-grade codebase context & memory engine built from scratch.
It provides line-exact code citations, AST parsing, and graph-RAG retrieval.

## Features
- Line-exact file range reader
- ReAct Agent execution loop with Gemini 2.5/3.6
- Qdrant Vector Search for semantic code retrieval
- Tree-sitter AST structural block extraction
